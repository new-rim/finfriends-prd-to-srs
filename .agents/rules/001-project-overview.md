# 001. 제품 개요 — FinFriends

## 무엇을 만드는가

**학습한 금융 지식을 실제 돈 행동으로 잇고, 그 변화를 보호자가 읽을 수 있게 하는 아동 금융교육 플랫폼**이다.

모든 요구사항은 아래 둘 중 하나에 귀속된다. **어느 쪽에도 귀속되지 않는 기능은 만들지 않는다.**

- **선언 ①** — 아이에게 **성장이 일어난다** (학습 → 실천)
- **선언 ②** — 그 성장이 보호자에게 **보인다** (실천 → 변화의 증거)

## 범위

| 영역 | 내용 |
| --- | --- |
| 학습 | 4영역(벌기·잘 쓰기·모으기·불리기) 커리큘럼 및 퀴즈 |
| 실천 판정 | **3경로** — 미션 승인 · 소비 회고 · 위시리스트 달성 |
| 별 지급 엔진 | 트리거 8종 · 차감형 · 주기 초기화 없음 · **저금통과 완전 분리** |
| 성장 표현 | 성장 나무 · 월간 숲 — 누적이 아니라 **전월 대비 변화**, 정체 시 **원인을 조건 단위로** 표시 |
| 소비 | 계획 카드(결제 전 기록) + 결제 후 **두 갈래 회고**(지킴 ⭐1 / 넘김 회고만) · 계획↔실제 업종 대조 |
| 온보딩 | 보호자 온보딩 5단계 · **법정대리인 동의 게이트** — 동의 완료가 아동 화면 진입의 선행 조건 |
| 보상·알림 | 승인 지연 시 **⭐ 소급 지급** · 아동 **3일 미접속 알림** |
| 결제 | 제휴사 위탁 구조(선불업 B안) 기반 아동 선불카드 충전·결제·해지 |
| 계측 | 인앱 이벤트 10종 및 실시간 성과 집계 |

## 명시적 제외 — 누락이 아니라 결정된 제외

| 제외 | 근거 |
| --- | --- |
| **소비 순간 자동 개입**(위치 알림 · 사전 개입 트리거) | ADR-002 — 사전 수단은 **계획 카드**가 대신한다 |
| **위치정보 수집 일체** | ADR-002 — 요건을 회피한 것이 아니라 **요건이 발생하지 않는 구조** |
| 앱 외부 현금 · 친구 기능 · 모의투자 · 미션 사진 인증 | 제품 범위 결정 |
| 아동 대상 유료 구독 | ADR-005 — 보호자·아동 모두 무료 |
| 네이티브 앱 · 별도 백엔드 · 자체 AI 서버 · 별도 CI/CD | `C-TEC-001`·`002`·`005`·`007` |

> **좌표·얼굴 필드는 스키마에 존재할 수 없다.** 게이트 G2가 `schema.prisma`와 마이그레이션을 스캔해 `lat`·`lng`·`geo`·`face`·`photo`를 막는다. 이것은 성능 최적화가 아니라 **규제 계층 1**이다.
