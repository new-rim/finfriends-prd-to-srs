| | | **합계** | **17** | H 4 | **6** | |

**착수 순서** — `FR-001` → `FR-002` → (`FR-003` · `FR-004` **병렬**). FR-003과 FR-004는 둘 다 FR-002만 선행으로 두므로 동시에 갈 수 있다.

**Stage 1이 지는 AC — §8 배분 6건 + 1차 확인 1건**

| AC | 귀속 | 판정 |
| --- | --- | --- |
| `AC-T14.1` | FR-001 | Preview 비인증 접근 불가 · Preview DB가 운영이 아님 |
| `AC-T13.1` | **FR-045** *(§8 배분)* · FR-001에서 **1차 확인** | 함수 `icn1` · DB `ap-northeast-2` 일치 |
| `AC-T4.1` | FR-003 *(FR-045와 공유)* | 동시 200명 10분 · 커넥션 고갈 0건 |
| `AC-T5.1` | FR-003 *(FR-045와 공유)* | 타 보호자 조회 0행 |
| `AC-T5.2` | FR-003 *(FR-045와 공유)* | `app`↔`pii` 조인 권한 오류 |
| `AC-T3.1` | FR-004 *(FR-045와 공유)* | 동일 키 10회 동시 → 원장 1건 |
| `AC-T19.1` | FR-004 *(FR-045와 공유)* | 서로 다른 100건 → `balance_after` 단조 증가 |

> 「공유」는 **정식 검증 설비가 FR-045(횡단 검증)에 있다**는 뜻이다. Stage 1의 각 이슈는 **1차 확인**을 마치고 넘기며, 릴리스 게이트 판정은 FR-045가 진다.
>
> **`AC-T13.1`은 §8이 FR-045에만 배분한 항목이다.** 다만 리전 고정은 FR-001이 실제로 수행하는 설정이므로, 그 이슈의 DoD에 **1차 확인 항목으로만** 넣었다 — §8 배분표는 고치지 않는다.
