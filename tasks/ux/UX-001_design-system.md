## 🎯 Summary

- **기능명:** 색·간격·라운드·타이포 **CSS 변수** · 아동/보호자 **테마 분기** · shadcn/ui **컴포넌트 목록** · **접근성 기준** · **아동용 문구 체계**.
- **목적:** C-TEC-004의 목적은 *"AI가 일관된 디자인 코드를 생성하도록 강제"* 인데, **강제는 컴포넌트 목록이 먼저 있을 때만 작동한다** — 목록이 없으면 매번 새 컴포넌트가 생긴다(SRS §6.8).
- **⚠️ 이 이슈만 디자인 전용이다** — UI/UX 트랙 9건 중 유일하게 대응 화면이 없고, **유일하게 FR 선행이 없다.**

### 🎨 이 이슈의 위치

- 🔴 **`FR-001`(플랫폼 셋업·스타일 진입점)을 막는다.** 토큰·테마·컴포넌트 목록이 없으면 `globals.css` 단일 진입점의 **내용이 비어 있다.**
- 🔴 **나머지 UI/UX 8건이 전부 이것을 전제한다.** 여기서 정한 토큰·컴포넌트를 각 화면이 쓴다.
- 따라서 **전체에서 가장 먼저 착수할 수 있고, 가장 먼저 끝나야 하는 이슈**다.

## ✅ Task Breakdown (실행 계획)

**(구 UX-001) 디자인 토큰**
- [ ] 색·간격·라운드·타이포를 **CSS 변수**로 정의 — `globals.css` 한 곳에
- [ ] 하드코딩 값이 화면에 흩어지지 않게 **토큰만 쓰는 규칙**을 명시

**(구 UX-002) 테마 분기**
- [ ] 🔴 아동/보호자 테마를 **변수로만 분기** — 컴포넌트를 복제하지 않는다
- [ ] `(ops)` 테마도 함께 정한다

**(구 UX-003) 컴포넌트 목록**
- [ ] shadcn/ui에서 **쓸 컴포넌트를 확정**하고 목록화 — Card · RadioGroup · Progress · Table · Dialog · Checkbox · Tabs · Alert · Form · Select · Input · Accordion · Badge
- [ ] **커스터마이즈 규약** — 컴포넌트는 복사본이므로 일괄 갱신 대상이 아니다(§10.1). 수정 시 지켜야 할 선을 정한다
- [ ] `src/components/ui/**` 배치 규칙

**(구 UX-004) 접근성**
- [ ] 🔴 **아동 화면 터치 타깃 ≥ 44px · 대비 4.5:1**
- [ ] **색만으로 상태를 구별하지 않는다** — 문구·아이콘 병행 규칙(승인 대기 3종·회고 갈래에 직결)

**(구 UX-005) 아동용 문구 체계**
- [ ] 🔴 **4영역 명칭을 확정**하고 각각 **한 줄 설명**을 붙인다(CON-REG-02 · REQ-NF-014)
- [ ] 「곧 열려요」 · 「아직 기록이 없어요」 등 **빈 상태·대기 상태 문구**의 톤 기준
- [ ] 아동이 읽을 수 있는 수준인지 검수 기준

## 🧪 Acceptance Criteria (BDD/GWT)

> §8 배분표는 이 이슈에 AC를 직접 배분하지 않는다 — 여기서 정한 것이 **다른 이슈의 AC 판정 근거**가 되기 때문이다. 아래는 성립시켜야 할 전제다.

**Scenario 1: 토큰 단일 출처**
- **Given:** 완성된 디자인 시스템 / **When:** 화면 코드에서 색·간격 값을 찾는다
- **Then:** **전부 CSS 변수 참조**다 — 하드코딩 0건.

**Scenario 2: 테마가 변수로만 갈린다**
- **Given:** 아동 화면과 보호자 화면 / **When:** 같은 컴포넌트를 쓴다
- **Then:** **변수 값만 다르고 컴포넌트는 하나**다 — 복제본이 없다.

**Scenario 3: 아동 접근성 (UI/UX 8건의 전제)**
- **Given:** 아동 화면 컴포넌트 / **When:** 터치 타깃과 대비를 잰다
- **Then:** **≥ 44px · 4.5:1**을 만족한다.

**Scenario 4: 4영역 명칭 확정 (AC-2.4 · CON-REG-02의 전제)**
- **Given:** 학습 원고(`FR-014`)와 나무 화면(`UX-004`)
- **When:** 4영역 명칭을 대조한다
- **Then:** **완전히 같다** — 두 곳에서 다르게 부르지 않는다.

## ⚙️ Technical & Non-Functional Constraints

- 🔴 **스타일 단일 경로:** `globals.css` 외 CSS **0건** · CSS-in-JS **0건** · 인라인 `style` **0건**(REQ-TEC-012). 게이트 G5(`FR-005`)가 이후 이를 강제한다
- 🔴 **컴포넌트는 복사본이다** — shadcn/ui는 일괄 갱신 대상이 아니다(§10.1). 커스터마이즈 규약이 없으면 매 화면에서 갈라진다
- **규제:** 4영역 명칭·한 줄 설명은 CON-REG-02 · REQ-NF-014 — 아동이 이해할 수 있어야 한다
- **접근성:** 성인 기준으로 만들면 아동이 못 누른다
- **범위:** 화면 구현은 `UX-002`~`UX-009`, 스타일 진입점 연결은 `FR-001`
