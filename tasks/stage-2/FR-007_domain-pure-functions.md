## 🎯 Summary

- **기능명:** 나무 승급 · 정체 판정 · 계획 대조 · WPA 카운트를 **DB·React 어디에도 의존하지 않는 순수 함수**로 분리한다.
- **목적:** 같은 판정이 **RSC에서도, Server Action에서도, `pg_cron` 배치의 대조에서도 같은 답**을 내야 한다. 판정이 컴포넌트나 쿼리 안에 섞이면 **배치가 만든 값과 화면이 만든 값이 갈라지고**, 그 순간 REQ-NF-006(정합성 0%)을 검증할 기준 자체가 사라진다.
- **왜 단독 이슈인가:** 임계 경로에서 갈라지는 지점이며, 조회(FR-018)·배치(FR-032·033)·Command(FR-017·025)가 **모두 같은 함수를 부른다.**

## ✅ Task Breakdown (실행 계획)

- [ ] `src/domain/` 모듈 신설 — **DB 클라이언트·React·Next.js를 import하지 않는다.** 입력은 평범한 값 객체만 받는다
- [ ] **나무 승급 판정** — 4영역 각각의 학습·퀴즈·실천 조건을 받아 승급 여부를 반환. **학습·퀴즈를 초과 충족해도 실천이 모자라면 승급하지 않는다**(AC-2.2)
- [ ] **미충족 조건 산출** — 승급하지 못한 이유를 **조건 단위로 전부** 반환하고, **가장 적게 남은 조건**을 식별한다(ACE-3.1 · ACE-2.3)
- [ ] **정체 판정** — `stall_days` 산출. **주기 시작 후 14일 경과분에만** 적용해 주기 초기화 직후를 정체로 표시하지 않는다(ACE-3.2 · 오탐 0건)
- [ ] **계획 대조** — 결제 합계 ≤ 계획 금액인지 판정하고 `planMatch` / `categoryMatch`를 **분리해서** 반환. 한 계획에 복수 결제면 **합계로 판정**한다(ACE-4.1)
- [ ] **업종 불일치 분기** — 금액은 이내인데 업종이 다르면 `plan_met=true` · `category_met=false`(ACE-4.2)
- [ ] **WPA 카운트** — 주간 실천 아동 수 산출 규칙. 소급 귀속분은 **완료 시점 주기**에 넣는다(ACE-6.2)
- [ ] 각 함수에 **단위 테스트** — 경계값(0건 · 조건 정확히 충족 · 14일 경계 · 금액 동일)
- [ ] 이후 게이트 G3(FR-005)가 `domain/`의 import 그래프를 검사할 수 있도록 **의존성을 명시적으로** 유지

## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 학습 초과 충족으로는 승급하지 않는다 (AC-2.2)**
- **Given:** 학습만 완료하고 실천 0건인 아동
- **When:** 퀴즈를 추가로 풀어 학습·정답 조건을 **초과 충족**한다
- **Then:** **나무 단계가 상승하지 않고**, 미충족 조건으로 **「실천 N회 남음」** 이 산출된다.

**Scenario 2: 미충족 조건을 조건별로 반환 (ACE-2.3)**
- **Given:** 실천 조건은 충족했으나 학습·퀴즈가 미충족
- **When:** 승급 판정을 호출한다
- **Then:** **승급하지 않고**, 남은 조건이 **조건별로 각각** 반환된다.

**Scenario 3: 주기 초기화 직후는 정체가 아니다 (ACE-3.2)**
- **Given:** 주기가 막 초기화된 정상 상태
- **When:** 정체 판정을 호출한다
- **Then:** **「정체」로 판정하지 않는다** — 오탐 **0건**.

**Scenario 4: 같은 입력 → 같은 답**
- **Given:** 동일한 입력 값 객체
- **When:** 조회 경로·배치 경로에서 각각 호출한다
- **Then:** **완전히 같은 값**을 반환한다 — 이것이 REQ-NF-006 검증의 기준이다.

## ⚙️ Technical & Non-Functional Constraints

- **순수성:** DB·React·Next.js 비의존. **부작용 없음 · 같은 입력 → 같은 출력**
- **정합성:** 배치(FR-032·033)와 화면(FR-018·037)이 **같은 함수를 부른다.** 각자 구현하면 값이 갈라지고 REQ-NF-006을 검증할 수 없다
- **정확성:** ACE-3.2의 **오탐 0건** — 정체 판정은 아동·보호자 신뢰에 직결된다
- **성능:** 순수 함수이므로 **캐시 대상이 아니다.** 배치가 대량으로 부르므로 입력당 할당을 줄인다

## ⚠️ 판정이 갈라지면 무엇이 무너지나

배치가 만든 `stall_days`와 화면이 계산한 값이 다르면, **어느 쪽이 맞는지 판정할 기준이 없다.** REQ-NF-006(정합성 0%)은 「기준이 하나뿐일 때」만 검증 가능한 요구사항이다. 이 모듈이 그 기준이다.
